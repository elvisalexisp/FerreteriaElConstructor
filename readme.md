# 🛠️ Ferretería El Constructor

Sistema web de e-commerce y gestión de inventario.

## 🚀 Instalación Local
1. Copia la carpeta del proyecto en `C:\xampp\htdocs\`.
2. Enciende **Apache** y **MySQL** desde XAMPP.
3. Entra a phpMyAdmin, crea una base de datos llamada **`ferreteria-constructor1`** e importa el archivo **`ferreteria-constructor1.sql`**.
4. Abre el sistema en tu navegador:
